# Beam Designer

Beam Designer is a Python desktop app for analyzing a single simply supported
or cantilever beam under vertical point and uniform loads. It displays support
reactions, shear, bending moment, deflection, and preliminary bending-stress
and deflection checks. Designs can be saved or opened, and results can be
exported as CSV or as a PDF calculation sheet.

## Requirements

No third-party Python packages are required. The app uses Python's standard
library, including Tkinter. Install the Tk support for your Python distribution
if it is not already included.

## Start the app

From the project directory, run:

```powershell
python beam_designer.py
```
